PROJECT OVERVIEW
================================================================================
Easy Trade is a web-based trading application designed to simplify trade tracking,
P&L calculations, and trading strategy management.

Target Stack: Python, FastAPI, SQLAlchemy, SQLite (MVP) / PostgreSQL (Phase 2)
Frontend: HTML5, CSS3, Vanilla JavaScript, Chart.js

CURRENT IMPLEMENTATION DETAILS
================================================================================

API ENDPOINTS (Trades):
  POST /api/trades/               - Create new trade
  GET /api/trades/                - Get all trades (with filtering)
  GET /api/trades/{id}            - Get specific trade
  PUT /api/trades/{id}            - Update trade (close with exit price)
  DELETE /api/trades/{id}         - Delete trade

API ENDPOINTS (Statistics):
  GET /api/stats/summary          - Overall trading statistics
  GET /api/stats/monthly          - Monthly breakdown
  GET /api/stats/performance      - Detailed performance metrics

Database Model (Trade):
  - id (integer, primary key)
  - ticker (string, uppercased)
  - entry_price (float)
  - exit_price (float, nullable)
  - quantity (float)
  - entry_date (datetime)
  - exit_date (datetime, nullable)
  - is_closed (boolean)
  - notes (text, nullable)

Utility Functions:
  - calculate_pnl() - Calculate profit/loss in currency
  - calculate_pnl_percentage() - Calculate P&L as percentage
  - is_winning_trade() - Determine if trade is profitable
  - calculate_average() - Statistical average
  - round_to_decimals() - Decimal precision rounding
  - get_month_string() - Format month from datetime

Statistics Calculated:
  - Total P&L (absolute and percentage)
  - Win rate percentage
  - Average win/loss
  - Largest win/loss
  - Winning vs losing trades count
  - Profit factor
  - Expectancy
  - Risk/reward ratio
  - Monthly breakdown

================================================================================
TECHNICAL DECISIONS
================================================================================

Database Choice:
  - MVP: SQLite (simple, file-based, no external dependencies)
  - Phase 2: PostgreSQL (scalability, reliability for production)

API Framework:
  - FastAPI: Modern, fast, built-in OpenAPI documentation

ORM:
  - SQLAlchemy: Mature, flexible, supports multiple databases

Frontend Communication:
  - REST API with JSON payloads
  - CORS enabled for development and production

Authentication:
  - JWT tokens (for Phase 2)
  - API key support (for MetaTrader integration in Phase 3)
