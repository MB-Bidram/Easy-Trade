DATABASE SCHEMA OVERVIEW
================================================================================

Project Table:
  - id: UUID (Primary Key)
  - name: String(255) [NOT NULL, UNIQUE]
  - description: Text [NULLABLE]
  - type: Enum("checklist", "market_overview", "journal") [DEFAULT: "checklist"]
  - created_at: DateTime [DEFAULT: now()]
  - updated_at: DateTime [DEFAULT: now()]
  - is_archived: Boolean [DEFAULT: False]
  - compressed_file_path: String [NULLABLE] (path to .zip file)
  - metadata: JSON [NULLABLE] (custom key-value pairs)
  - total_items: Integer [DEFAULT: 0]
  - version: Integer [DEFAULT: 1]

Checklist Table:
  - id: UUID (Primary Key)
  - project_id: UUID (Foreign Key -> Project.id)
  - title: String(255) [NOT NULL]
  - description: Text [NULLABLE]
  - is_template: Boolean [DEFAULT: False]
  - completion_percentage: Float [DEFAULT: 0.0]
  - total_items: Integer [DEFAULT: 0]
  - completed_items: Integer [DEFAULT: 0]
  - created_at: DateTime [DEFAULT: now()]
  - updated_at: DateTime [DEFAULT: now()]

ChecklistItem Table:
  - id: UUID (Primary Key)
  - checklist_id: UUID (Foreign Key -> Checklist.id)
  - title: String(255) [NOT NULL]
  - description: Text [NULLABLE]
  - is_completed: Boolean [DEFAULT: False]
  - completed_at: DateTime [NULLABLE]
  - order: Integer [NOT NULL]
  - priority: Enum("low", "medium", "high") [DEFAULT: "medium"]
  - notes: Text [NULLABLE]

Note Table:
  - id: UUID (Primary Key)
  - project_id: UUID (Foreign Key -> Project.id)
  - title: String(255) [NOT NULL]
  - content: Text [NOT NULL]
  - created_at: DateTime [DEFAULT: now()]
  - updated_at: DateTime [DEFAULT: now()]
  - tags: JSON [NULLABLE] (array of strings)

Image Table:
  - id: UUID (Primary Key)
  - project_id: UUID (Foreign Key -> Project.id)
  - filename: String(255) [NOT NULL]
  - file_path: String [NOT NULL]
  - file_size: Integer [NOT NULL] (bytes)
  - mime_type: String(50) [NOT NULL]
  - uploaded_at: DateTime [DEFAULT: now()]
  - description: Text [NULLABLE]
  - width: Integer [NULLABLE]
  - height: Integer [NULLABLE]

ProjectTable Table:
  - id: UUID (Primary Key)
  - project_id: UUID (Foreign Key -> Project.id)
  - name: String(255) [NOT NULL]
  - description: Text [NULLABLE]
  - created_at: DateTime [DEFAULT: now()]
  - updated_at: DateTime [DEFAULT: now()]
  - row_count: Integer [DEFAULT: 0]
  - column_count: Integer [DEFAULT: 0]
  - data: JSON (columns and rows structure)

Trade Table (Existing):
  - id: Integer (Primary Key)
  - project_id: UUID [NULLABLE] (Foreign Key -> Project.id)
  - ticker: String [NOT NULL]
  - entry_price: Float [NOT NULL]
  - exit_price: Float [NULLABLE]
  - quantity: Float [NOT NULL]
  - entry_date: DateTime [NOT NULL]
  - exit_date: DateTime [NULLABLE]
  - is_closed: Boolean [DEFAULT: False]
  - notes: Text [NULLABLE]

================================================================================
PROJECT COMPRESSION STRATEGY
================================================================================

File Format: ZIP (optimized)
Location: ./projects/{project_id}/project.zip

Contents Structure:
  project.zip
  ├── project.json          (metadata, timestamps, version info)
  ├── checklists/
  │   ├── checklist_1.json  (checklist data with items)
  │   └── checklist_2.json
  ├── notes/
  │   ├── note_1.txt        (plain text)
  │   └── note_2.txt
  ├── images/
  │   ├── image_1.jpg       (compressed on upload)
  │   └── image_2.png
  ├── tables/
  │   ├── table_1.json      (CSV or JSON format)
  │   └── table_2.json
  └── metadata.json         (checksums, file listing)

Compression Settings:
  - Compression Level: 9 (Maximum)
  - Decompression Required: Yes (never used in-zip)
  - Encryption: None (Phase 2)
  - Backup: Previous 5 versions kept

Size Estimation:
  - Project metadata: 5-10 KB
  - Per note (avg): 5-15 KB
  - Per image (compressed): 100-500 KB
  - Per table (avg): 10-50 KB
  - Typical project total: 10-50 MB
  - Large project (many images): 50-100 MB
