  ├─ id: UUID (PK)

  ├─ created_at: DateTime
  └─ updated_at: DateTime

ChecklistItem Table:
  ├─ id: UUID (PK)
  ├─ checklist_id: UUID (FK)
  ├─ title: String(255)
  ├─ description: Text
  ├─ is_completed: Boolean
  ├─ completed_at: DateTime
  ├─ order: Integer
  ├─ priority: Enum("low", "medium", "high")
  └─ notes: Text

Note Table:
  ├─ id: UUID (PK)
  ├─ project_id: UUID (FK)
  ├─ title: String(255)
  ├─ content: Text

  ├─ created_at: DateTime

Image Table:

  ├─ width: Integer
  ├─ height: Integer
  ├─ uploaded_at: DateTime
  └─ description: Text

ProjectTable Table:
  ├─ id: UUID (PK)
  ├─ project_id: UUID (FK)
  ├─ name: String(255)
  ├─ description: Text
  ├─ columns: JSON (array of column definitions)
  ├─ rows: JSON (array of row data)
  ├─ created_at: DateTime
  └─ updated_at: DateTime

PROJECT COMPRESSION FORMAT
================================================================================

File Format: ZIP (Maximum compression level 9)
Location: ./projects/{project_id}/project.zip

Structure:
  project.zip
  ├── project.json
  │   └─ {
  │      "id": "uuid",
  │      "name": "Project Name",
  │      "description": "...",
  │      "type": "checklist",
  │      "created_at": "2026-08-24T09:00:00Z",
  │      "updated_at": "2026-08-24T09:00:00Z",
  │      "version": 1,
  │      "checksum": "sha256hash"
  │    }
  ├── metadata.json
  │   └─ {
  │      "compression_date": "2026-08-24T09:00:00Z",
  │      "file_size_bytes": 12345,
  │      "total_items": 25,
  │      "total_images": 3,
  │      "total_notes": 5,
  │      "file_list": [...]
  │    }
  ├── checklists/
  │   ├── checklist_uuid_1.json
  │   └── checklist_uuid_2.json
  ├── notes/
  │   ├── note_uuid_1.txt
  │   └── note_uuid_2.txt
  ├── images/
  │   ├── uuid_image1.jpg (compressed)
  │   └── uuid_image2.jpg (compressed)
  └── tables/
      ├── table_uuid_1.json
      └── table_uuid_2.json

Size Optimization:
  - Compression Level: 9 (maximum)
  - Images: Pre-compressed with PIL (JPEG, quality 85)
  - JSON: Minified (no extra whitespace)
  - Typical reduction: 40-60% smaller than uncompressed

Metadata Tracking:
  - Compression date/time
  - File size in bytes
  - Total items count
  - File listing with checksums
  - Version information
  - Complete file inventory
